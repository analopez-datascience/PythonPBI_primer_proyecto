# PythonPBI_primer_proyecto
Integración de Python con Power BI 

Este es un proyecto dónde vamos a conectar power BI con los datos de dos modos diferentes a fin de obtener el mismo resultado, por un lado el modo clásico de conexión de Power BI, y por otro mediante un script de Python, para ello previamente hemos creado en local nuestro entorno para trabajar. También replicamos el dashboard con ambas conexiones e incluimos gráficas realizada con Python en el segundo dashboard.
